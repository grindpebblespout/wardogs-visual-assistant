# Documentation

## Overview
WARDOGS Visual Assistant adds a tactical overlay layer to WARDOGS for solo and private sessions.

## Overlay Modules
- Player ESP — highlights player positions
- Skeleton / Box ESP — alternative styles
- Distance Indicators — real-time range display
- Target / Squad / Objective Markers
- Custom HUD — crosshair, ammo, health

## Config
Settings stored in `%APPDATA%\WDVA\config.json`.
